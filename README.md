# Previsão do Tempo

Aplicação web responsiva para consultar a previsão do tempo por cidade.

## Acesso

- Site: https://leonardojiahao-bit.github.io/previsao-do-tempo/
- Repositório: https://github.com/leonardojiahao-bit/previsao-do-tempo

## Funcionalidades

- Consulta de clima por cidade.
- Previsão para os próximos dias.
- Alternância entre tema claro e escuro.
- Interface responsiva para desktop e dispositivos móveis.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## Como executar localmente

Abra o arquivo `index.html` no navegador ou execute um servidor local na pasta do projeto.
