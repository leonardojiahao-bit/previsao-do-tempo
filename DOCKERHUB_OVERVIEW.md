# Previsão do Tempo

Aplicação web responsiva para consultar o clima com a API Open-Meteo e salvar cidades favoritas em um banco PostgreSQL no Supabase. A interface é servida por Nginx Alpine.

## Executar

```bash
docker run -d -p 8080:80 --name previsao-tempo leonardojiahao/bootcamp2-app:1.1
```

Abra `http://localhost:8080`.
